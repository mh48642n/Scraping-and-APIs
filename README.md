# Scraping-and-APIs

## Purpose of this Repository
As most of my projects revolve around macroeconomic projects it would prompt me to use the numerous
government APIs and surveys that are available to perform tests of causal inference.

The folder data_apis is where majority of the APIs are and where most of the work begins. As some of you may already know, the documentation 
for many of these APIs are less than subpar. So, to make my life easier, and maybe yours, I am attempting to document 
the major series for BLS, BEA and FRED.


I will end up using a class that uses SQLite, helping save the data to a local database and then I will
begin to use this data to conduct tests with economic theories. These theories would include Okun's Law, 
the Philips Curve, and respective theories in Fiscal Economics and Monetary Policy.
